## **Spectra CLI**
A simple launcher, made for complete fun, Not intended for production use, Maybe for fun.

<hr />

It's pretty easy to setup, Just clone the repo

```
git clone https://github.com/imiakk/SpectraCLI/
```

Then cd into it.

```
cd SpectraCLI
```

Install all the dependencies

```
npm install
```

And finally, Run it!

```
npm run dev
```
